# Roadmap

```
MVP Product → Video Demo → Landing Page → Marketing
```

## Phase 1 — MVP

full auth · template gallery (skripsi/makalah/surat) · single-shot generate ·
editor · export DOCX · Midtrans hard paywall · admin AI config/monitor/safety.
Product good enough to record.

## Phase 2 — Video

60–90s demo, **multi-doc showcase**. Show: pilih template → isi form →
generate → export DOCX, lintas skripsi + makalah + surat.
Plus 3 short clips for TikTok/Reels, screenshots, sample DOCX.

## Phase 3 — Landing Page

hero · video · problem · solution · how it works · features ·
templates gallery · sample DOCX · pricing/early access · FAQ · disclaimer · CTA.

## Phase 4 — Marketing

Small validation first. Target: 50 waitlist · 10 beta · 3 paid.
Channel: TikTok, Reels, X, WA kampus groups. Problem-based content.

## Targets

- semester akhir students (skripsi/tugas)
- mahasiswa & pekerja yang butuh surat/dokumen cepat
- working students
